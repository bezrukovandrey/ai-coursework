# AI Coursework

This repository contains a set of practical AI and machine learning labs, covering both foundational theory and applied modelling tasks.

## Repository structure

- `lab1/` — Introductory AI/Python notebook and first practical exercises.
- `lab2/` — Supervised learning lab focused on classification and support vector machines (SVM).
- `lab3/` — Unsupervised learning lab covering clustering and data structure discovery.
- `lab4/` — Applied ML task using microbiome abundance data to classify IBD status.
- `lab6/` — Theory-heavy lab on supervised learning, classification, neural networks, deep learning, and symbolic AI.
- `lab7/` — Time-series forecasting with recurrent neural networks, including RNN and LSTM models.
- `symbolic/` — Symbolic AI example using pyDatalog to model relationships in a Game of Thrones-style dataset.

## Lab topics

### Lab 1
Introduction to AI workflows in Python, including notebooks and basic task setup. This lab establishes the foundation for later experiments.

### Lab 2
Supervised learning with a dataset and SVM-based classification. The focus is on learning decision boundaries and training models on labelled data.

### Lab 3
Unsupervised learning, including clustering and pattern extraction without labelled examples. This lab explores how models can discover hidden structures in data.

### Lab 4
Applied machine learning on biological data. The project uses microbiome abundance features to predict a binary condition (such as IBD status).

### Lab 6
Covers key AI concepts: supervised vs. unsupervised learning, classification, neural networks, and symbolic reasoning. It combines theoretical notes with practical demonstrations.

### Lab 7
Introduces recurrent neural networks and LSTMs for sequence prediction. The task focuses on forecasting time-dependent data such as humidity measurements.

### Symbolic AI
A logic-based example using pyDatalog to represent family relations and infer facts such as siblings, cousins, and ancestors.

## Purpose
The repository is intended for coursework and hands-on learning in artificial intelligence, machine learning, deep learning, and symbolic reasoning.
